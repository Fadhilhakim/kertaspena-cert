# Sertifikat Otomatis — KERTAS PENA

Implementasi vanilla HTML/CSS/JS sesuai README.md proyek. Data peserta adalah JSON statis per kegiatan.

## Kode kegiatan
- Pelatihan Membaca Nyaring: `MN`
- Resensi Buku: `RB`
- Pelatihan Pembuatan Poster dan Pengelolaan Media Sosial Komunitas: `PMS`
- Workshop Menulis Konten Budaya Lokal: `KBL`

Kode ini dipakai untuk format nomor sertifikat dan dapat diubah di `js/events-config.js`.

## Asset
File PNG di `assets/` adalah placeholder yang sengaja dapat diganti dengan file desain asli tanpa mengubah struktur aplikasi.
